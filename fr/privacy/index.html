Politique de confidentialité

Dernière mise à jour : octobre 2026.

Responsable du traitement

Archè SELARL, 57 Quai de Grenelle, 75015 Paris, France, est responsable des données personnelles collectées via ce site. Contact : paris@archelegal.com.

Ce que nous collectons

Ce site n'utilise ni cookies, ni traceurs publicitaires, ni outils d'analyse, et ne charge aucune police ni aucun script provenant de tiers. Nous ne recevons de données personnelles que lorsque vous nous écrivez : votre nom, votre adresse électronique, votre société, le sujet et votre message.

Finalités et base légale

Nous utilisons ces informations pour répondre à votre demande et, si vous devenez client, pour exécuter notre mission. La base légale est votre consentement lorsque vous nous contactez et notre intérêt légitime à répondre aux demandes.

Durée de conservation

Les demandes qui ne donnent pas lieu à une mission sont supprimées après 12 mois. Les dossiers clients sont conservés pendant les durées imposées par la loi et par les règles professionnelles.

Confidentialité

Les avocats sont tenus au secret professionnel. N'envoyez pas de documents confidentiels via le formulaire de contact.

Vos droits

Vous pouvez demander l'accès, la rectification, l'effacement ou la limitation de vos données, ou vous opposer à leur traitement, en écrivant à paris@archelegal.com. Vous pouvez aussi saisir la CNIL (cnil.fr).

Hébergement

Ce site est hébergé par GitHub Pages (GitHub, Inc., États-Unis). GitHub peut traiter des données techniques telles que les adresses IP pour diffuser les pages.
